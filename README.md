# GitHub Commits Last Page

A Chrome extension (Manifest V3) that adds a “Go to last commits page” context menu item to GitHub commit lists.

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the folder containing `manifest.json`.
5. When updating the extension, click its reload button on `chrome://extensions`.

## Usage

On a GitHub commits page, right-click and select **Go to last commits page**.
